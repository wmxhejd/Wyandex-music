**Wyandexmusic** - *неофициальный* плеер яндекс музыки, с упором на повторение функционала оригинала, но в более оптимизированном формате
> [!NOTE]
> **На данный момент поддерживаются только ОС на базе ядра Linux**

## Установка:
### 1 способ:
```bash
git clone https://github.com/wmxhejd/Wyandex-music.git
cd Wyandex-music
./install.sh
```
### 2 способ:
Скачать `.AppImage`, `.deb` или `.rpm` из [релизов](https://github.com/wmxhejd/Wyandex-music/releases) и запустить
